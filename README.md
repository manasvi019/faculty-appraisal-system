# Faculty Self-Appraisal System

A web-based system designed to automate faculty self-appraisal and support career advancement evaluation in higher education institutions.

## Project Objective
The system enables faculty members to submit academic activities such as publications, seminars, projects, and lectures, while administrators can review and manage appraisal records efficiently.

## Features (Planned)
- Faculty self-appraisal submission
- Admin review and record management
- Event, publication, and project tracking
- PDF report generation
- Secure login system

## Current Status
Project is currently in analysis and design phase. Implementation will begin in upcoming sprints.
